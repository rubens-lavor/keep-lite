### para execuutar os scripts abra o terminal na raiz do projeto keep-lite e rode o comando:

> k6 run k6-scripts/arquivo.js

onde:

- run k6 é o comando para rodar um script

- k6-script é a pasta onde se encotra os scripts (considerando que o ternimal foi aberto na pasta raiz)

- arquivo.js substitua elo nome do scritp que deseja rodar
